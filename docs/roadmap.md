# Roadmap

Before V1 public release: reconcile remaining fee-rounding/account/program exceptions against actual settlements; validate live product extraction; native panel/VoiceOver/zoom checks; representative usability testing; configured public repository, policy/support URLs and funding handles; branding clearance; Chrome review.

Nonblocking later improvements after first release: Filipino translations, NVDA test coverage, several named local cost profiles, import with explicit validation, improved exact minimum-price search, selected-variant compatibility expansion and additional program editor rows.

Only after demonstrated demand: historical fee configurations or paid maintained schedules through a typed data provider. Other Southeast Asian marketplaces would implement MarketplaceAdapter; none is shipped. No SaaS dashboard, account/database, inventory/order management, AI chat, automated financial action or unrelated scraping belongs in V1.
