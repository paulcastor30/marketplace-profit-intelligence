# Contributing

Use Node 24+ and pinned pnpm. Run pnpm install --frozen-lockfile, pnpm exec playwright install chromium and pnpm check before a PR. Include meaningful tests for fee changes and a primary-source evidence ledger with dates, basis, rounding, eligibility and caps. Never guess a current fee.

Keep V1 Shopee PH only. No tracking, remote executable code, automatic financial actions, credential access or backend. Prefer semantic native controls and plain language. Review all changes through beginner, older/nontechnical, screen-reader, keyboard-only, low-vision and experienced-seller personas.

Explain the user problem, resulting behavior, validation and limitations. Do not assert accessibility, financial settlement accuracy or release readiness without evidence. Contributions are under GPL-3.0-only. See CODE_OF_CONDUCT.md and SECURITY.md.
